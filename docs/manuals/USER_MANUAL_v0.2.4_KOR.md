## 1. 소개

MIRA는 Mass Spectrometry Imaging(MSI) 데이터를 탐색하기 위한 독립 실행형 데스크톱 뷰어입니다. 채널(m/z) 단위로 이온 이미지를 탐색하고, 개별 픽셀 또는 임의의 영역에서 스펙트럼을 확인하며, 공간 강도 프로파일을 측정하고, 출판 가능한 수준의 이미지를 내보낼 수 있습니다 — `.app`/`.exe`로 패키징된 이후에는 Python 환경 없이도 사용할 수 있습니다.

---

## 2. 지원 파일 형식

| 형식 | 확장자 | 비고 |
|---|---|---|
| imzML | `.imzML` (+ 동일 이름의 `.ibd`) | **Continuous**, **Processed** 모드 모두 지원 |
| 멀티채널 TIFF | `.tif`, `.tiff` | CYX / ZYX / YX 레이아웃, `tifffile`을 통해 채널 축 자동 감지 |

imzML 파일의 경우, 짝이 되는 `.ibd` 바이너리 파일이 `.imzML` 파일과 **같은 폴더**에 있어야 하며, 자동으로 함께 로드됩니다.

---

## 3. 설치 및 실행

전체 설치 방법(소스 직접 실행, macOS `.app` 빌드, Windows `.exe` 빌드)은 프로젝트 루트의 `README.md`를 참고하세요. 요약하면:

- **소스에서 실행**: `pip install -r requirements.txt` 후 `python main.py`
- **macOS**: `build_mac.sh` 실행 → `MIRA.app` 생성
- **Windows**: 로컬에서 `build_win.bat` 실행하거나, GitHub Actions로 빌드된 `.exe` 아티팩트를 다운로드

## 4. 메인 윈도우 구성

```
┌───────────────────────────────────────────────────────┐
│  메뉴바: File | Edit | View | Help                      │
│  툴바: [Open] [TIC Image] [Line Profile] [Zoom Reset]   │
├────────────────────────────┬───────────────────────────┤
│                            │   Global Spectrum          │
│      이온 이미지            ├───────────────────────────┤
│   (QGraphicsView 캔버스)    │   Pixel / ROI Spectrum     │
│                            │                            │
├────────────────────────────┴───────────────────────────┤
│  컨트롤: Channel 슬라이더 · m/z 입력 · Bin (Da) ·         │
│         밝기/대비 · 컬러맵 · Normalize                    │
├──────────────────────────────────────────────────────── ┤
│  Line Profile dock (하단, 기본 숨김 —                     │
│  라인을 처음 그리면 자동으로 열림)                          │
└───────────────────────────────────────────────────────┘
```

- 이미지 뷰와 스펙트럼 패널은 크기 조절이 가능한 수평 분할(splitter)로 배치되어 있습니다 (경계선을 드래그해 크기 조절).
- Line Profile 패널은 Qt의 dockable 패널입니다: 제목 표시줄을 드래그해 위치를 옮기거나, 별도 창으로 분리(float)하거나, 닫을 수 있습니다 — [12장](#12-라인-프로파일-ctrl드래그) 참고.

## 5. 파일 열기

1. `File → Open File…` (또는 `Ctrl+O`).
2. `.imzML`, `.tif`, `.tiff` 파일 중 선택.
3. **대용량 imzML 파일**의 경우 (채널 수가 설정된 임계값, 기본 **5,000**을 초과 — [환경설정](#17-환경설정) 참고): **Large File — Spectral Resolution** 다이얼로그가 표시되며 다음 중 선택할 수 있습니다:
   - **Full resolution** — 모든 채널을 그대로 로드 (렌더링/탐색이 느릴 수 있음).
   - **Bin at `X` Da** — 로드 전에 고정 폭의 Da 구간으로 m/z를 평균화해 실질 채널 수를 줄임. 예상 결과 채널 수가 실시간으로 미리보기됩니다.
4. 파일이 백그라운드에서 로드되는 동안 진행 다이얼로그가 표시됩니다 (UI는 계속 반응함).
5. 로드가 완료되면 상태 표시줄에 이미지 크기, 채널 수, 현재 모드, (해당 시) 적용된 load-time bin 폭이 표시됩니다.

새 파일을 열면 이전에 그려둔 ROI 박스와 라인 프로파일은 자동으로 초기화됩니다 (새 이미지 크기에서는 이전 픽셀 좌표가 더 이상 유효하지 않을 수 있기 때문입니다).

## 6. 이온 이미지 탐색

| 컨트롤 | 동작 |
|---|---|
| **Channel 슬라이더** (하단 패널) | 드래그하여 m/z 채널 / TIFF 채널 탐색 |
| **m/z SpinBox** | m/z 값을 입력하고 Enter → 가장 가까운 채널로 이동 |
| **마우스 휠** (이미지 위) | 커서를 중심으로 줌 인/아웃 |
| **Shift + 마우스 휠** | 줌 변경 없이 다음(+1) / 이전(−1) 채널로 이동 |
| **좌클릭 드래그** | 이미지 팬(이동) |
| **더블클릭** | 이미지가 뷰에 맞도록 줌 리셋 |

TIFF 파일의 경우 채널 축에 물리적인 m/z 의미가 없으므로, 라벨이 m/z 대신 단순 **채널 인덱스**("Ch")로 표시됩니다.

## 7. 마우스 조작 전체 정리

이미지 캔버스에서 사용 가능한 모든 마우스 제스처 요약:

| 제스처 | 동작 |
|---|---|
| 휠 스크롤 | 줌 인/아웃 (커서 중심) |
| Shift + 휠 스크롤 | m/z 채널 이동 (위=+1, 아래=−1) |
| 좌클릭 드래그 | 팬 (이미지 이동) |
| Shift + 좌클릭 | 픽셀 1개 선택 → 해당 픽셀 스펙트럼 표시 + 노란색 크로스헤어 |
| Shift + 좌클릭 드래그 | ROI 박스 그리기 → 박스 내부 픽셀들의 평균 스펙트럼 표시 ([11장](#11-roi-영역-스펙트럼-shift드래그) 참고) |
| Ctrl + 좌클릭 드래그 | 선 그리기 → 해당 선을 따라 공간 강도 프로파일 표시 ([12장](#12-라인-프로파일-ctrl드래그) 참고) |
| 우클릭 드래그 (상하) | 밝기 조절 (window center 이동) |
| 우클릭 드래그 (좌우) | 대비 조절 (window width 조정) |
| 더블클릭 | 줌 리셋 |

**설계 원칙**: `Shift`는 항상 *선택*(픽셀/ROI/채널)을 위해, `Ctrl`은 항상 *측정*(라인 프로파일)을 위해 사용됩니다. 두 드래그 제스처는 별도로 켜고 끄는 "모드" 없이 **항상 활성화**되어 있으며, 모디파이어 없는 좌클릭 드래그는 다른 무엇을 그려두었든 상관없이 항상 팬으로 동작합니다.

## 8. 밝기 / 대비

표시되는 강도 범위(`vmin`/`vmax`)를 조정하는 세 가지 동등한 방법:

1. **Min / Max 스핀박스** (컨트롤 패널) — 정확한 값을 직접 입력.
2. **이미지 위 우클릭 드래그** (ITK-SNAP 스타일):
   - **상하**로 드래그 → 밝기 조절 (window center 이동).
   - **좌우**로 드래그 → 대비 조절 (window width 조정).
3. **Auto 버튼** — 현재 표시 중인 채널의 강도 값 중 2%~98% percentile로 `vmin`/`vmax`를 자동 설정.

세 가지 방법은 서로 동기화되어 있어, 하나를 조정하면 나머지도 함께 갱신됩니다.

## 9. 컬러맵

컨트롤 패널의 **Colormap** 드롭다운에서 선택 가능:

| 이름 | 설명 |
|---|---|
| `gray` | 표준 그레이스케일 |
| `viridis` | 지각적으로 균일한 보라 → 파랑 → 청록 → 초록 → 노랑 |
| `hot` | 검정 → 빨강 → 주황 → 노랑 → 흰색 |
| `inferno` | 검정 → 보라 → 주황 → 노랑 |

`viridis`, `hot`, `inferno`는 `matplotlib` 의존성 없이 자체 구현된 근사 컬러맵입니다.

## 10. 스펙트럼 패널

화면 오른쪽에는 두 개의 플롯이 위아래로 배치되어 있으며, 모두 **stem plot**(각 m/z 피크마다 수직선 하나, 연결선/마커 없음) 형태로 그려집니다:

1. **Global Spectrum** — 파일 로드 시 한 번 계산되는, *모든* 픽셀의 강도 합산 스펙트럼. 현재 선택된 채널 위치에 빨간 점선 수직선이 표시됩니다.
2. **Pixel / ROI Spectrum** — 가장 최근의 선택 동작에 따라 갱신됩니다:
   - **Shift+클릭**으로 픽셀 선택 → 해당 픽셀의 raw 스펙트럼을 `Pixel Spectrum (x=.., y=..)` 라벨과 함께 표시.
   - **Shift+드래그**로 ROI 박스 선택 → 박스 내부 픽셀들의 평균 스펙트럼을 `ROI Spectrum (x: c0–c1, y: r0–r1)` 라벨과 함께 표시 ([11장](#11-roi-영역-스펙트럼-shift드래그) 참고).

두 스펙트럼 플롯 중 어디를 클릭해도 해당 m/z 채널로 뷰어가 이동합니다 (m/z 스핀박스에 직접 입력하는 것과 동일).

## 11. ROI 영역 스펙트럼 (Shift+드래그)

**기능 설명**: 이온 이미지 위에 사각형 영역을 선택하여, 단일 픽셀이 아닌 **선택 영역 내 모든 픽셀의 평균 스펙트럼**을 확인할 수 있습니다.

**사용 방법**:
1. `Shift`를 누른 채 이미지 위에서 좌클릭 드래그로 관심 영역에 박스를 그립니다.
2. 드래그하는 동안 반투명 노란색 사각형 오버레이가 실시간으로 커서를 따라 갱신됩니다.
3. 마우스 버튼을 놓으면:
   - 그려진 박스가 사실상 점 하나 수준(가로/세로 모두 약 2px 미만)이면, MIRA는 이를 일반 **Shift+클릭**으로 간주하여 단일 픽셀 스펙트럼을 대신 표시합니다 (박스가 아닌 노란색 크로스헤어로 표시).
   - 그 외의 경우, ROI 박스가 이미지 위에 그대로 유지되고, Pixel/ROI Spectrum 패널이 박스 내부 모든 픽셀의 **평균 스펙트럼**으로 갱신되며 `ROI Spectrum (x: c0–c1, y: r0–r1)` 라벨이 표시됩니다.
4. 언제든 새로운 ROI를 그리거나(또는 Shift+클릭으로 픽셀을 선택하면) 기존 ROI를 대체합니다 — 이번 버전에서는 한 번에 하나의 ROI만 유지됩니다.

**참고**:
- ROI 스펙트럼은 **정규화되지 않은 raw 평균값**입니다 — Normalize 드롭다운은 *표시되는 이미지*에만 영향을 주며, 단일 픽셀 스펙트럼과의 일관성을 위해 스펙트럼 값 자체에는 적용되지 않습니다.
- 새 파일을 열면 기존 ROI 오버레이는 자동으로 사라집니다.

## 12. 라인 프로파일 (Ctrl+드래그)

**기능 설명**: 이온 이미지 위에 직선을 그어, 현재 채널의 강도가 그 선을 따라 **공간적으로** 어떻게 변화하는지 확인할 수 있습니다.

**사용 방법**:
1. `Ctrl`을 누른 채 이미지 위에서 원하는 방향으로 좌클릭 드래그하여 선을 긋습니다.
2. 드래그하는 동안 청록색(cyan) 선 오버레이가 실시간으로 커서를 따라 갱신됩니다.
3. 마우스 버튼을 놓으면:
   - 선의 길이가 약 2px 미만이면 실수로 인식되어 무시됩니다.
   - 그 외의 경우 선이 확정되고 프로파일이 계산되며, 창 하단의 **Line Profile** dock 패널이 (아직 열려 있지 않았다면) 자동으로 열리고 x축 **Distance (px)**, y축 **Intensity** 그래프가 표시됩니다.
4. 언제든 새로운 선을 그으면 기존 선을 대체합니다 — 이번 버전에서는 한 번에 하나의 선만 유지됩니다.

**자동 동작**:
- 채널, 정규화 모드, bin 폭을 변경할 때마다 프로파일이 **자동으로 다시 계산**됩니다 — 선을 다시 그릴 필요가 없습니다.
- 툴바의 `Line Profile` 버튼과 `View → Line Profile` 메뉴 항목은 **동일한 하나의 토글**입니다 — 체크/해제는 dock 패널의 표시 여부만 제어하며, Ctrl+드래그 제스처 자체를 켜고 끄는 것이 **아닙니다** (제스처는 항상 사용 가능).
- dock의 제목 표시줄 **X** 버튼으로 닫으면 툴바/메뉴의 체크 상태도 자동으로 해제됩니다. 새로운 선을 그으면 다시 열리면서 체크 상태도 함께 켜집니다.
- 다른 Qt dock 위젯과 마찬가지로, 창의 다른 가장자리로 옮기거나 별도 창으로 "분리(float)"할 수 있습니다.
- 새 파일을 열면 현재 그려진 선과 오버레이가 초기화됩니다 (단, dock 패널 자체의 위치/표시 상태는 유지됩니다).

## 13. 채널 빈닝

MIRA는 서로 독립적인 두 종류의 m/z 빈닝을 지원합니다:

### 13.1 View-time 빈닝 ("Bin (Da)")

- 컨트롤 패널의 m/z 스핀박스 옆에 위치합니다.
- Da 단위의 bin 폭을 설정합니다 (기본값 `0` = 비활성화, 단일 채널 모드).
- 0보다 큰 값으로 설정하면, 표시되는 이온 이미지는 현재 선택된 m/z를 기준으로 `± (bin 폭 / 2)` 범위에 속하는 모든 채널의 **평균**(또는 **합**)이 됩니다.
- `View → Bin Mode → Mean / Sum`으로 집계 방식(평균/합)을 전환할 수 있습니다.
- 이 설정은 *표시되는 이미지*에만 영향을 주며, 사이드 패널에 표시되는 스펙트럼에는 영향을 주지 않습니다.

### 13.2 Load-time 빈닝 (대용량 파일용)

- 채널 수가 설정된 임계값(기본 5,000 — [환경설정](#17-환경설정) 참고)을 초과하는 imzML 파일에만 적용됩니다.
- 파일을 여는 시점에 다이얼로그로 표시됩니다 ([5장](#5-파일-열기) 참고): 파일이 완전히 로드되기 *전에* full resolution 또는 고정 Da 폭 빈닝 중 선택합니다.
- 매우 고해상도의 raw imzML 파일에서 메모리 사용량을 줄이고 렌더링/탐색 속도를 크게 향상시킵니다.
- 적용된 load-time bin 폭이 있다면 상태 표시줄에 표시됩니다.

---

## 14. TIC 이미지

`View → Show TIC Image` (또는 **TIC Image** 툴바 버튼)은 **Total Ion Current** 이미지 — 모든 채널에 걸친 픽셀별 강도 합산 이미지 —를 표시합니다. 특정 m/z 채널과 무관하게 조직/샘플의 전체적인 윤곽을 참고할 때 유용합니다.

---

## 15. 정규화

컨트롤 패널의 **Normalize** 드롭다운에서 다음을 선택할 수 있습니다:

| 모드 | 설명 |
|---|---|
| `none` | Raw 강도 값 (기본값) |
| `TIC` | 각 픽셀을 자신의 Total Ion Current로 정규화 |
| `RMS` | 각 픽셀을 자신의 root-mean-square 강도로 정규화 |
| `Median` | 각 픽셀을 자신의 median 강도로 정규화 |

정규화는 **표시되는 이미지**에만 영향을 줍니다. 재현성을 위해 Global/Pixel/ROI 스펙트럼 패널은 항상 정규화되지 않은 raw 값을 표시합니다.

---

## 16. 이미지 내보내기

`File → Export Image…` (`Ctrl+Shift+S`)는 현재 화면에 보이는 그대로(현재 채널/bin, 컬러맵, 밝기/대비)를 파일로 저장합니다.

**옵션**:
- **포맷**: PNG, JPG, TIFF 중 선택.
- **스케일 바** (선택 사항): 켜면 다음을 설정할 수 있습니다:
  - **단위**: µm, nm, px.
  - **길이**: 선택한 단위 기준 스케일 바의 길이.
  - **픽셀 크기**: imzML 메타데이터에서 가능하면 자동으로 채워짐 (없거나 TIFF 파일인 경우 직접 입력 가능); 물리 단위를 픽셀로 환산하는 데 사용됩니다.
  - **위치**: bottom-right 또는 bottom-left.
- 내보내기 해상도는 원본 이미지의 픽셀 크기 그대로입니다 (업샘플링 없음).

| 설정 | 설명 | 기본값 |
|---|---|---|

환경설정은 `QSettings`를 통해 저장되며 세션 간에 유지됩니다.

## 19. 알려진 제한 사항

- m/z 직접 탐색 컨트롤은 **SpinBox만** 제공되며, 전체 채널 목록을 보여주는 드롭다운은 없습니다. imzML 파일은 흔히 수천~수만 개의 채널을 포함하므로 목록 나열 방식은 비현실적이며, m/z 값을 직접 입력하거나(또는 load-time 빈닝으로 채널 수를 줄여서) 사용하는 것이 의도된 워크플로입니다.
- 이번 버전에서는 ROI 박스와 라인 프로파일 모두 한 번에 **하나씩만** 활성화할 수 있습니다 (다중 영역 비교는 이후 릴리즈에서 계획되어 있음).
- `viridis`, `inferno` 컬러맵은 matplotlib과 완전히 동일하지 않은, 수작업으로 튜닝된 근사값입니다.
- Processed 모드 imzML 파일은 모든 픽셀의 m/z 값의 합집합으로 공유 m/z 축을 구성하므로, 매우 큰 데이터셋에서는 느릴 수 있습니다.
- Lazy loading(500 MB 초과 파일)은 픽셀/ROI/라인 조회 시마다 디스크에서 다시 읽으므로, 대용량 파일에는 빠른 SSD를 권장합니다.
