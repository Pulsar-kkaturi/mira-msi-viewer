# MIRA 사용자 매뉴얼

**Mass spectrometry Imaging & Review App**
**버전:** 0.3.5
**업데이트:** 2026.09.03
**적용 범위:** MIRA v0.3.5

MIRA는 Mass Spectrometry Imaging(MSI) 데이터를 위한 독립 실행형 데스크톱 뷰어입니다. 이온 이미지 탐색, 픽셀 및 다중 ROI 스펙트럼 비교, 공간 라인 프로파일, 4-pane RGB 컬로컬라이제이션, 즐겨찾기 채널 마커, 이미지와 스펙트럼 내보내기를 지원합니다.

## 1. 지원 파일 및 실행

### 지원 파일

| 형식 | 확장자 | 비고 |
|---|---|---|
| imzML | `.imzML` 및 짝이 되는 `.ibd` | Continuous 및 Processed 모드 |
| TIFF | `.tif`, `.tiff` | 2D 또는 멀티채널 데이터. 4D 입력은 첫 번째 Z/T 슬라이스 사용 |

imzML 데이터셋의 `.ibd` 파일은 `.imzML`과 기본 파일명이 같아야 하며 같은 폴더에 있어야 합니다. TIFF 채널은 물리적인 m/z 값 대신 채널 인덱스로 표시됩니다.

### 실행

- 소스 실행: `requirements.txt`의 패키지를 설치한 후 `python main.py`를 실행합니다.
- macOS 및 Windows에서는 프로젝트 빌드 스크립트로 만든 패키지 앱을 실행할 수 있습니다.
- 현재 설치 및 빌드 방법은 `README.md`를 참고하세요.

## 2. 창, 화면 구성 및 제목

MIRA는 한 번에 최대 **3개의 독립 메인 창**을 유지할 수 있습니다. `File → New Window`(`Ctrl+N` 또는 플랫폼의 표준 New 단축키)를 선택해 새 창을 엽니다. 이미 창이 3개 열려 있으면 경고를 표시하고 추가 창을 만들지 않습니다.

각 창은 다음 상태를 독립적으로 관리합니다.

- 로드한 데이터셋과 현재 채널
- 줌, 밝기, 컬러맵, 정규화 및 bin 설정
- ROI 선택과 ROI 표시 모드
- 라인 프로파일과 각 팝업 창
- RGB 컬로컬라이제이션 상태

메인 화면은 다음으로 구성됩니다.

1. 왼쪽 이온 이미지 캔버스
2. 오른쪽 Global Spectrum 및 Pixel/ROI Spectrum 플롯
3. 컬로컬라이제이션 중에만 나타나는 RGB 오버레이 컨트롤
4. 하단 채널, 즐겨찾기, 밝기, 컬러맵, 정규화 및 bin 컨트롤

파일을 열기 전 창 제목은 `MIRA`입니다. 파일을 성공적으로 로드하면 로드한 파일의 기본 이름을 사용한 `MIRA — 파일명`으로 바뀝니다. 각 독립 창은 자신의 제목만 갱신합니다.

## 3. 데이터 열기

1. `File → Open File…`(`Ctrl+O`)을 선택합니다.
2. imzML 또는 TIFF 파일을 고릅니다.
3. imzML 채널 수가 설정된 임계값(기본 **5,000**)보다 많으면 다음 중 하나를 선택합니다.
   - **Full resolution**
   - 고정 Da 폭의 load-time binning
4. MIRA가 백그라운드에서 데이터를 읽는 동안 진행 상태를 표시합니다.
5. 상태 표시줄에서 크기, 채널 수, 데이터 모드와 해당되는 경우 load-time bin 폭을 확인합니다.

Load-time binning은 일반 탐색 전에 raw m/z 샘플을 고정 폭 구간별로 평균화합니다. Processed imzML의 사전 채널 수는 샘플 픽셀을 바탕으로 한 추정값입니다.

한 창에서 파일을 열어도 다른 MIRA 창에는 영향을 주지 않습니다.

## 4. 이온 이미지 탐색

| 컨트롤 | 동작 |
|---|---|
| Channel 슬라이더 | m/z 또는 TIFF 채널 이동 |
| m/z / Ch 입력 필드 | 값을 입력하고 확정하여 가장 가까운 채널로 이동 |
| ☆ / ★ | 현재 채널을 이 파일의 세션 즐겨찾기에 추가 또는 제거 |
| Favorites 드롭다운 | 저장한 즐겨찾기를 선택해 해당 채널로 즉시 이동 |
| 마우스 휠 | 포인터를 중심으로 확대/축소 |
| Shift + 마우스 휠 | 줌 변경 없이 이전/다음 채널로 이동 |
| 좌클릭 드래그 | 이미지 팬 |
| 더블클릭 | 이미지를 화면에 맞춤 |
| 스펙트럼 플롯 클릭 | 클릭한 x 위치에 가장 가까운 채널로 이동 |

스펙트럼 플롯에는 현재 채널이 빨간 점선 수직선으로 표시됩니다. RGB 컬로컬라이제이션 중에는 화면을 대표하는 단일 채널이 없으므로 오버레이를 끌 때까지 슬라이더 입력, Shift+휠 및 스펙트럼 클릭 채널 이동이 비활성화되거나 무시됩니다.

## 5. 마우스 조작

| 제스처 | 동작 |
|---|---|
| 좌클릭 드래그 | 이미지 팬 |
| Shift + 클릭 | 한 픽셀 선택, raw 스펙트럼과 노란 크로스헤어 표시 |
| Shift + 좌클릭 드래그 | 사각형 ROI 추가 |
| Ctrl + 좌클릭 드래그 | 라인 프로파일 추가 |
| 우클릭 상하 드래그 | 밝기 이동 |
| 우클릭 좌우 드래그 | 대비 변경 |
| 휠 | 줌 |
| Shift + 휠 | 채널 이동 |
| 더블클릭 | 줌 리셋 |

가로와 세로가 모두 약 2픽셀보다 작은 Shift+드래그는 픽셀 선택으로 처리됩니다. 길이가 약 2픽셀보다 짧은 Ctrl+드래그는 무시됩니다.

별도의 ROI 모드나 라인 모드를 켜지 않아도 선택 제스처를 항상 사용할 수 있습니다. 단, RGB 컬로컬라이제이션 중에는 새 라인 프로파일을 만들 수 없습니다.

## 6. 밝기, 컬러맵 및 정규화

### 밝기 및 대비

일반 단일 채널 이미지에서는 다음 방법을 사용합니다.

- **Min**, **Max** 입력 필드로 정확한 표시 범위를 설정합니다.
- 우클릭을 상하로 드래그해 밝기를, 좌우로 드래그해 대비를 조정합니다.
- **Auto**는 현재 표시된 채널 또는 view-time bin에서 0이 아닌 값의 2 percentile을 Min으로, 전체 값의 98 percentile을 Max로 설정합니다.

이 컨트롤은 렌더링에만 영향을 주며 저장된 raw 스펙트럼은 바꾸지 않습니다.

### 컬러맵

단일 채널 컬러맵은 `gray`, `viridis`, `hot`, `inferno`를 제공합니다. 회색 이외의 컬러맵은 matplotlib 없이 제공되는 내장 근사값입니다.

### 정규화

| 모드 | 표시 이미지 |
|---|---|
| `none` | Raw intensity |
| `TIC` | 각 픽셀의 Total Ion Current로 나눔 |
| `RMS` | 각 픽셀의 root-mean-square intensity로 나눔 |
| `Median` | 각 픽셀의 median intensity로 나눔 |

정규화는 채널 이미지, view-time binned 이미지와 그 표시값에서 계산하는 라인 프로파일에 영향을 줍니다. Global, Pixel 및 ROI 스펙트럼은 항상 raw 값입니다.

## 7. 스펙트럼 패널

오른쪽에는 크기를 조절할 수 있는 두 개의 stem plot이 있습니다.

- **Global Spectrum**은 모든 픽셀의 raw 합계입니다.
- **Pixel/ROI Spectrum**은 선택한 픽셀 스펙트럼과 표시 중인 ROI 스펙트럼을 보여줍니다.

Shift+클릭으로 픽셀을 선택하면 기본 Pixel Spectrum 곡선이 갱신되고 크로스헤어가 나타납니다. ROI를 추가하면 ROI 비교가 명확하도록 픽셀 곡선과 크로스헤어가 지워집니다. 이후 활성 ROI 곡선을 하단 플롯에서 함께 비교할 수 있습니다.

일반 단일 채널 보기 상태에서 두 플롯 중 하나를 클릭하면 가장 가까운 채널로 이동합니다.

### 즐겨찾기 채널 마커

m/z/Ch 입력 필드 옆의 `☆` 버튼으로 현재 채널을 즐겨찾기에 등록합니다. 등록된 채널에서는 버튼이 `★`로 바뀌며, 모든 즐겨찾기는 파란색 Global Spectrum stem 뒤에 주황색 짧은 점선으로 표시됩니다. 더 굵은 분홍색 긴 점선은 계속 현재 채널을 나타냅니다.

옆의 **Favorites** 드롭다운은 저장된 채널을 m/z/Ch 오름차순으로 표시하며, 항목을 선택하면 기존 채널 이동 경로로 즉시 이동합니다. 한 번에 최대 10개 항목을 보여주고 그보다 많으면 macOS를 포함한 모든 플랫폼에서 세로 스크롤을 사용합니다. 즐겨찾기는 현재 MIRA 창의 파일 경로별로 앱 실행 중에만 유지됩니다. 같은 창에서 같은 경로를 다시 열면 드롭다운과 마커가 복원되지만, 다른 창이나 앱 재실행과는 공유하지 않습니다. 마커 위치를 클릭해도 가장 가까운 채널로 이동합니다. Pixel/ROI Spectrum에는 표시하지 않으며, 컬로컬라이제이션이 일반 컨트롤을 비활성화한 동안에는 변경할 수 없습니다.

## 8. 다중 ROI 비교

MIRA는 메인 창마다 최대 **5개의 사각형 ROI**를 지원합니다.

### ROI 추가 및 식별

1. `Shift`를 누른 채 좌클릭으로 사각형을 드래그합니다.
2. MIRA가 1–5 중 첫 번째 빈 슬롯을 할당합니다.
3. 이미지에 ROI 슬롯 색상과 번호가 표시됩니다.
4. 하단 스펙트럼 플롯 위에 슬롯 색상, 픽셀 수, 양 끝을 포함한 x/y 범위, **Visible** 체크박스와 삭제 버튼이 있는 행이 나타납니다.

5개 슬롯의 색상은 고정되어 있습니다. ROI를 삭제하면 슬롯이 비며, 다음 ROI가 첫 번째 빈 슬롯을 사용합니다. 모든 슬롯이 사용 중이면 여섯 번째 ROI 요청은 거부되고 기존 선택은 유지됩니다.

### Mean 및 Total

**ROI intensity** 선택은 화면에 표시하고 CSV로 내보내는 모든 ROI 곡선에 적용됩니다.

- **Mean per pixel**: 사각형에 포함된 모든 픽셀의 raw 평균 스펙트럼
- **Total (sum of all pixels)**: 평균 스펙트럼에 사각형 픽셀 수를 곱한 합계

이 설정은 Global Spectrum을 바꾸지 않습니다. ROI 스펙트럼은 raw 값이며 이미지 정규화, 밝기, 컬러맵 및 view-time binning의 영향을 받지 않습니다.

### 표시 및 삭제

- **Visible**을 해제하면 데이터를 삭제하지 않고 해당 ROI 사각형과 스펙트럼 곡선을 숨깁니다.
- 행의 `✕` 버튼으로 ROI를 삭제하고 슬롯을 비웁니다.
- 툴바 **Clear** 또는 `View → Clear Annotations`로 모든 ROI를 한 번에 삭제합니다.

## 9. 라인 프로파일

MIRA는 메인 창마다 최대 **5개의 라인 프로파일**을 동시에 지원합니다.

1. `Ctrl`을 누른 채 이미지 위에 선을 좌클릭 드래그합니다.
2. MIRA가 첫 번째 빈 라인 슬롯을 할당하고 번호가 붙은 cyan 선을 표시합니다.
3. 별도의 **비모달** `Line Profile N` 팝업이 열립니다. 끝점 좌표, 픽셀 단위 기하학적 길이와 Distance (px) 대 Intensity 플롯을 표시합니다.

팝업이 비모달이므로 메인 창을 계속 조작하고 여러 라인 창을 함께 비교할 수 있습니다. 프로파일 값은 현재 표시된 단일 채널 이미지에서 샘플링되며 채널, 정규화 또는 view-time bin이 바뀌면 자동으로 다시 계산됩니다.

라인 프로파일 팝업을 닫는 동작은 **해당 라인을 삭제**하고, 오버레이를 제거하며, 슬롯을 비웁니다. 5개 프로파일이 활성 상태라면 새 선을 그리기 전에 팝업 하나를 닫으세요.

툴바 **Clear** 또는 `View → Clear Annotations`는 모든 라인 팝업을 닫고 모든 라인을 삭제합니다. 라인 프로파일은 dock 패널이 아닌 팝업이며, View 메뉴에는 라인 프로파일 표시 항목이 없습니다.

## 10. 4-Pane RGB 컬로컬라이제이션

체크 가능한 툴바 **Colocalization** 또는 `View → Colocalization Overlay`를 선택합니다. **Overlay Controls (R/G/B)** 패널이 나타납니다.

이미지 캔버스는 다음과 같은 동기화된 논문용 2×2 배치로 바뀝니다.

```text
Red    | Green
Blue   | Merge
```

R, G, B 각 행에는 다음 항목이 있습니다.

- 해당 색상 채널을 **Merge**에 포함할지 정하는 체크박스
- 가장 가까운 채널로 해석되는 m/z 입력 필드(TIFF는 Ch)
- 독립적인 **Min**, **Max** 표시 범위
- 선택 채널의 0이 아닌 값 2 percentile을 Min으로, 전체 값 98 percentile을 Max로 설정하는 **Auto**

세 행은 모두 활성화된 상태로 시작합니다. 각 개별 pane은 Min/Max에 따라 0–255로 독립 스케일링되며 체크를 해제해도 red, green 또는 blue tint 상태로 계속 표시됩니다. 활성 채널만 Merge에 가산 합성되고, 세 체크를 모두 해제하면 Merge만 검은색이 됩니다. Max가 Min보다 큰 유효한 범위를 설정해야 하며, 처음에는 Auto 사용을 권장합니다.

### 동작 및 제약

- 네 pane의 줌, 팬, 더블클릭 리셋, 픽셀 크로스헤어, ROI 및 기존 라인 오버레이는 같은 원본 좌표로 동기화됩니다.
- 어느 pane에서든 픽셀 또는 ROI를 선택할 수 있습니다. 다른 pane까지 넘어간 ROI 드래그는 시작 pane 경계에서 제한됩니다.
- 오버레이 패널이 활성화되면 일반 채널, 밝기, 컬러맵, 정규화 및 bin 컨트롤이 비활성화됩니다.
- RGB 행은 오버레이를 켜기 전에 선택한 정규화, view-time bin 폭 및 Mean/Sum bin 모드를 계속 사용합니다.
- Shift+클릭 픽셀 스펙트럼 및 Shift+드래그 ROI는 전체 raw 스펙트럼을 조회하므로 계속 사용할 수 있습니다.
- RGB 합성에는 단일 강도 채널이 없으므로 새 Ctrl+드래그 라인 프로파일은 차단됩니다.
- 우클릭 밝기/대비와 단일 채널 이동은 적용되지 않습니다.
- 기존 라인 프로파일 팝업은 열린 상태를 유지하지만 RGB 합성을 나타내지는 않습니다.
- 이미지 내보내기는 pane 텍스트 레이블 없이 전체 2×2 grid를 저장하며 scale bar는 Merge pane에 배치합니다.
- `View → Show TIC Image`는 컬로컬라이제이션을 끄고 TIC 이미지를 표시합니다.
- 컬로컬라이제이션을 끄면 이전 현재 채널의 일반 단일 채널 보기로 돌아갑니다.

## 11. 채널 빈닝

MIRA는 서로 독립적인 두 빈닝 단계를 제공합니다.

### View-time binning

하단 컨트롤의 **Bin (Da)**를 설정합니다.

- `0`은 단일 채널을 표시합니다.
- 양수 폭은 선택 m/z를 중심으로 `± 폭/2`에 포함되는 채널을 결합합니다.
- `View → Bin Mode → Mean`은 채널을 평균합니다.
- `View → Bin Mode → Sum`은 채널을 합산합니다.

View-time binning은 표시 이온 이미지, RGB 원본 채널 및 라인 프로파일에 영향을 줍니다. Global, Pixel 및 ROI 스펙트럼은 바꾸지 않습니다.

### Load-time binning

imzML 채널 수가 Preferences 임계값을 넘으면 파일 열기 다이얼로그에서 로드 전에 스펙트럼 해상도를 낮출 수 있습니다. Load-time binning은 로드된 m/z 축을 변경하므로 이후의 모든 이미지와 스펙트럼에 반영됩니다.

---

## 12. TIC 이미지

`View → Show TIC Image` 또는 툴바 **TIC Image**를 선택하면 모든 채널을 픽셀별로 합산한 이미지를 표시합니다. MIRA가 2/98 percentile 표시 범위를 자동 적용합니다.

TIC 표시는 RGB 컬로컬라이제이션을 종료합니다. 이후 일반 채널을 선택하면 이온 이미지로 돌아갑니다.

---

## 13. 이미지 및 스펙트럼 내보내기

### Export Image

`File → Export Image…`(`Ctrl+Shift+S`)는 현재 렌더링된 이미지를 PNG, JPG 또는 TIFF로 저장합니다. 현재 단일 채널 컬러맵과 표시 범위 또는 pane 이름을 덧씌우지 않은 고정 순서의 Red/Green/Blue/Merge 2×2 컬로컬라이제이션 grid가 반영됩니다.

선택적 스케일 바는 다음을 지원합니다.

- µm, nm 또는 px 단위
- 사용자 지정 길이 및 좌하단/우하단 위치
- 가능한 경우 메타데이터에서 읽은 픽셀 크기 또는 직접 입력값

단일 채널 내보내기는 원본 데이터 크기를 사용합니다. 컬로컬라이제이션 내보내기는 작은 간격으로 분리된 원본 크기 pane 네 개를 사용하고 scale bar는 Merge 안에 표시합니다. 인터랙티브 ROI, 크로스헤어 및 라인 주석은 이미지에 그려 넣지 않습니다.

### Export Global Spectrum

`File → Export Global Spectrum…`은 다음 열을 가진 CSV를 저장합니다.

- 첫 열: `m/z` 또는 `Channel`
- `Global Intensity`: 모든 픽셀의 raw 합계

### Export ROI Spectra

`File → Export ROI Spectra…`는 ROI가 하나 이상 있을 때 활성화됩니다. x축 열 다음에 활성 ROI마다 슬롯 순서대로 열 하나를 기록합니다. 헤더에는 ROI 번호와 범위가 포함됩니다. 값은 현재 **Mean per pixel** 또는 **Total** 선택을 따릅니다.

숨긴 ROI도 활성 상태이므로 ROI CSV에 포함됩니다. 내보내기에서 제외하려면 해당 ROI를 삭제하세요. 필요하면 MIRA가 `.csv` 확장자를 자동으로 붙입니다.

## 14. 환경설정

환경설정은 데이터 로드 전후 모두 열 수 있습니다.

- **macOS:** `MIRA → Preferences…`
- **Windows/Linux:** `Settings → Preferences…`

**Large-file channel threshold**는 imzML 데이터에 스펙트럼 해상도 선택 다이얼로그를 표시할 기준을 정합니다. 기본값은 5,000채널이고 설정 범위는 1,000–100,000입니다. 값은 세션 간 저장됩니다.

## 17. 초기화 및 파일 변경 동작

### Clear

툴바 **Clear**와 `View → Clear Annotations`는 다음을 삭제합니다.

- 모든 ROI 박스 및 ROI 스펙트럼
- 선택 픽셀 크로스헤어 및 픽셀 곡선
- 모든 라인 오버레이 및 라인 프로파일 팝업

로드한 파일, 현재 채널, 줌, 밝기, 컬러맵, 정규화, bin 설정 및 RGB 토글 상태는 유지합니다.

### 같은 창에서 다른 파일 열기

새 파일을 성공적으로 로드하면 다음 동작을 수행합니다.

- ROI, 픽셀 선택 및 모든 라인 프로파일 삭제
- 모든 라인 프로파일 팝업 닫기
- RGB 컬로컬라이제이션 끄기
- ROI intensity를 Mean per pixel로 초기화
- 새 데이터셋의 컨트롤, 스펙트럼, 상태 및 창 제목 초기화

다른 메인 창에는 영향을 주지 않습니다.

즐겨찾기 채널은 현재 앱 세션 동안 정규화된 파일 경로별로 따로 유지됩니다. 같은 창에서 이전 파일을 다시 열면 해당 즐겨찾기가 복원되며, MIRA를 종료하면 모두 폐기됩니다.

## 18. 알려진 제한 사항

- 메인 창은 최대 3개, 창당 ROI는 최대 5개, 라인 프로파일은 최대 5개까지 활성화할 수 있습니다.
- RGB 컬로컬라이제이션은 정확히 3개의 가산 색상 슬롯(R/G/B), 슬롯별 가장 가까운 채널 하나와 고정 2×2 배치를 지원합니다.
- RGB 컬로컬라이제이션은 RGB 인식 라인 프로파일을 만들지 않습니다. 단일 채널 모드에서 선을 그리세요.
- 즐겨찾기 채널은 세션 동안만 유지되며 창 사이에서 공유되지 않습니다.
- m/z 탐색기는 모든 채널 목록이 아닌 숫자 입력 필드입니다.
- Processed imzML은 관측된 모든 m/z 값으로 공유 축을 만들기 때문에 로드가 느릴 수 있습니다.
- 500MB보다 큰 imzML binary 데이터는 lazy access를 사용하므로 반복적인 이미지, ROI 또는 스펙트럼 조회가 느릴 수 있습니다. SSD 사용을 권장합니다.
- `viridis`와 `inferno`는 matplotlib와 완전히 같은 맵이 아닌 내장 근사값입니다.
